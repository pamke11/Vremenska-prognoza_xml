# Vremenska Prognoza (Weather App)

Ovo je samostalni projekt izrađen u svrhu Podatkovna povezanost i digitalna infrastruktura. Aplikacija omogućuje korisniku unos imena grada, nakon čega dohvaća i prikazuje trenutne podatke o vremenu (temperatura i opis).

## Korištene tehnologije
- **HTML5**: Struktura stranice.
- **CSS3**: Vizualni dizajn i responzivnost.
- **JavaScript**: Logika aplikacije.
- **OpenWeatherMap API**: Izvor podataka o vremenu.

## Kako pokrenuti projekt
1. Kloniraj ili preuzmi ovaj repozitorij.
2. Otvori `index.html` u svom pregledniku.
3. U `script.js` datoteci potrebno je imati vlastiti API ključ s [OpenWeatherMap](https://openweathermap.org/api) stranice.
